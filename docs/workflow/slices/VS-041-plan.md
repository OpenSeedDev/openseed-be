# VS-041 20자 제목·키워드 검색

## 사용자 결과

Guest를 포함한 사용자는 최대 20자의 검색어로 현재 랭킹에 게시된 아이디어의 제목과 키워드를 검색하고, 공개 범위와 관계없이 랭킹 카드와 같은 안전한 7개 필드만 확인한다.

## 근거와 선행 조건

- 백로그: VS-041, 선행 VS-040, resource lock `ranking`, `search`
- GitHub 증거: VS-040 PR #79가 `a0199e72ff6d5585d82d2d5061fad6490c8126ba`로 2026-07-23T02:33:55Z에 Merge됨
- 통합 기획서 13.3과 기능 명세 HOME-04·HOME-05

## 포함 범위

- 인증 없이 `GET /api/v1/search?q=` 제공
- 앞뒤 공백을 제거한 1~20자 검색어 검증
- 제목 또는 연결된 키워드를 PostgreSQL `ILIKE`로 부분 일치 검색
- `%`, `_`, `\`는 검색 와일드카드가 아닌 일반 문자로 처리
- 현재 랭킹에 존재하는 Published 아이디어만 랭킹순으로 반환
- `PUBLIC`, `SEMI_PUBLIC`, `MATCHING`에 같은 7필드 카드 반환
- 아이디어별 중복 키워드 일치에도 카드 한 건만 반환
- OpenAPI·IdeaKeyword Migration·ERD 갱신

## 제외 범위

- 카테고리·공개 범위 필터, 복합 검색, 정렬 선택, 페이지네이션
- 상세 아이디어 공개 범위 정책 변경
- 검색 자동완성, 검색 기록, 전문 검색 인덱스와 검색어 분석
- 키워드 편집 API

## API와 데이터 영향

- 요청: `GET /api/v1/search?q={query}`
- 응답: 랭킹 카드와 동일한 `rank`, `rankChange`, `title`, `summary`, `category`, `companyInterestCount`, `likeCount`
- DB: `idea_keywords(id, idea_id, keyword)`와 아이디어별 정규화 키워드 유일성·검색 보조 인덱스 추가

## 인수 조건과 테스트 목록

- [ ] 제목 대소문자 비구분 부분 일치 결과를 랭킹순으로 반환한다.
- [ ] 키워드 대소문자 비구분 부분 일치 결과를 반환한다.
- [ ] 제목과 여러 키워드가 동시에 일치해도 카드가 중복되지 않는다.
- [ ] 앞뒤 공백은 제거하고 검색하며 공백만 또는 20자 초과 검색은 400이다.
- [ ] 검색어의 SQL 와일드카드 문자는 문자 그대로 검색한다.
- [ ] 세 공개 범위에 같은 7필드만 반환한다.
